# ReelDock — 인스타 릴스/스토리 원본 화질 다운로더 + 미디어 도구

## 기능
- 링크 여러 개 붙여넣기 → 동시 다운로드, 화질 선택(원본 최고/1080/720/480/오디오만)
- 재인코딩 없음: 해상도 → fps → 비트레이트 순 최고 품질 그대로 저장
- 스토리 전체 받기(사용자명), 중복 건너뛰기, 썸네일 저장, 최근 다운로드 기억
- 갤러리(받은 파일 보기/열기/삭제), 비공개 금고(PIN 뒤 앱 전용 폴더로 숨김, 암호화 아님)
- 도구(PC, ffmpeg 내장): 동영상 자르기·30초 분할·압축·GIF·MP4 변환·속도 / 오디오 추출·자르기·변환·볼륨 정규화
- 다크/라이트 모드

## 빌드
GitHub Actions → build → Run workflow → Artifacts에서 `ReelDock-exe`, `ReelDock-apk` 다운로드

## 주의
- Android: 설정 > 앱 > ReelDock > "모든 파일 접근" 허용 필요. 폰에는 ffmpeg가 없어 도구 탭은 PC 전용입니다.
- 본인 콘텐츠/허락받은 콘텐츠에만 사용. sessionid는 비밀번호와 같으니 공유 금지.

## 유튜브 / 기타 사이트
- 유튜브(영상·음악·라이브·재생목록), 기타 yt-dlp 지원 사이트 링크도 붙여넣으면 받아집니다.
- "화질 · 용량 미리보기": 해상도/fps별 예상 용량을 보고 골라 받기, 오디오 원본/MP3 선택, 라이브 처음부터 녹화.
- PC는 deno(JS 런타임)를 EXE에 포함해 유튜브 해독을 처리합니다. 폰은 이 기능이 없어 일부 영상만 받아질 수 있습니다.
